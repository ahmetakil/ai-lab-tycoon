# Audio credits

All sounds in this folder (the sound effects and `music_loop.mp3`) are
procedurally generated by `tool/audio/generate_audio.py` from oscillators,
envelopes, filters and noise. No third-party samples, loops or recordings
are used. Everything is original to AI Lab Tycoon.

Regenerate with Python 3 + numpy + scipy and ffmpeg (libmp3lame):

    python3 -m venv /tmp/audio-venv && /tmp/audio-venv/bin/pip install numpy scipy
    /tmp/audio-venv/bin/python tool/audio/generate_audio.py
